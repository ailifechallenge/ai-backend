# ActionGuard Travel 3.1.1 · 2026-10-17

바탕화면 `ActionGuard-Team-Integrated`의 3.1.0 다음 사용성 수정 버전입니다.

## 수정 사항
- 국가 변경은 상단 종 옆 버튼에서만 합니다. 위치 검색·일정 장소·좌표 직접 등록·공식 경보·시설 지도·관심 지역 설정의 별도 미국/일본 선택기를 제거했습니다.
- 장소 검색기는 상단 국가를 직접 참조합니다. 다른 국가의 GPS 위치를 받으면 임의로 국가를 바꾸지 않고 안내합니다. 선택 국가와 다른 검색 결과도 등록 목록에 섞지 않습니다.
- 국가 전환 시 입력 중 장소와 이전 비동기 조회 결과를 초기화합니다. 일정 입력의 기본 시간대도 새 국가 기준으로 바뀝니다. 다른 국가의 기존 저장 일정은 새 등록 전까지 보존합니다.
- 이전 버전에서 상단 선택 국가와 조회 위치 국가가 다르게 저장된 경우 조회 위치만 비우고 일정을 유지합니다.
- 미국 홈·분석 화면·기상 경보 안내에는 일본 지진/쓰나미 바로가기와 기본 안내를 표시하지 않습니다. 일본에서는 해당 기능을 유지합니다.
- 경보 결과의 ‘시간·지역 등 핵심 정보’를 접지 않고 모든 요약 항목을 처음부터 표시합니다.
- Category 1~5가 원문/번역에 등장하면 풍속 등급 설명을 붙입니다. Category 4는 1분 평균 최대 지속풍속 시속 209~251km 범위와 피해 의미를 설명하고 한국의 태풍 강도/대피 단계와 구분합니다. 숫자만 보고 임의의 등급을 만들지 않습니다. 번역에만 있거나 원문과 등급이 다르면 미확인/불일치를 명시합니다.
- 번역 프롬프트에서도 생소한 Category 용어를 한국어로 풀어 설명하도록 했습니다. 기존 전체 번역의 원문 숫자·등급을 임의로 바꾸지는 않습니다.
- 헤더의 긴 제목을 ‘내 일정’, ‘경보 해석’으로 정리하고 글자 크기와 패딩을 줄여 국가 버튼/종과 겹치거나 과도하게 줄바꿈되지 않도록 조정했습니다.
- 홈의 빈 상태에는 불필요한 ‘원문 입력’ 배지를 제거하고 선택 국가에 맞는 검색 안내를 표시합니다. 장소 검색·일정 폼·핵심 사실·안내 카드 간격을 정리했습니다.
- 공식 행동지침은 첫 세 문장을 바로 표시합니다. 긴 나머지는 추가 행동으로 펼쳐 봅니다. 문장 중간을 잘라 명령이나 조건을 바꾸지 않습니다.
- 새 용어 안내가 기존 `aside`용 고정 메뉴 스타일을 상속하여 하단바를 가리는 문제를 제거했습니다.

## 검증
- 프론트엔드 172개 테스트 통과. 국가 고정, 다른 국가 GPS 거절, 한국어 등급 설명, 원문/번역 불일치, 핵심 정보 기본 노출, 국가별 링크, 일정 저장 회귀 테스트 포함.
- 백엔드 435개 통과, 기존 2개 skip. 타입 검사·프로덕션 웹 빌드 성공. 기존 번들 크기 경고 유지.
- 402 × 874 CSS px / 브라우저 100%에서 실제 기존 괌 태풍 경보 화면의 핵심 정보 기본 노출, 미국에서 일본 바로가기 제거, 용어 설명과 하단 메뉴 가림 여부를 확인했습니다.
- 실제 기기 설치·네이티브 푸시 수신과 운영 배포 상태는 3.1.0과 동일합니다. 이번 패치로 검증됐다고 표시하지 않습니다.
