# 팀 프론트엔드 원본 디자인 복원

2026-10-16: 사용자가 다시 제공한 ai-frontend-dev.zip을 디자인 기준으로 적용했습니다.

- 임의로 추가한 reference-design.css는 더 이상 불러오지 않습니다.
- 원본 tokens/global CSS 및 버튼·카드·헤더·아이콘 하단 탭·배지·홈·소개 슬라이드·챗봇·대비 CSS 모듈을 직접 사용합니다. 14개 파일은 ZIP과 바이트 단위 일치합니다(TEAM_DESIGN_RESTORE.json).
- 소개는 원본 3장 슬라이드로 복원했습니다. 완료 처리는 현재 통합 앱의 상태에 연결합니다. 미국·일본 지원 범위와 실제 동작 한계에 맞춰 설명만 수정했습니다.
- 홈은 원본 PageHeader/Card/Button/StatusBadge와 Home/AlertCard CSS 모듈로 구성하고 현재 workspace의 실제 경보·번역·지시·위치·일정을 연결합니다. 경보가 없으면 입력/조회 화면으로 안내하며 시연 경보를 실정보로 넣지 않습니다.
- 하단은 원본 아이콘 4개 탭으로 복원했습니다. 긴급 연락은 원본 홈 연락 카드 형식을 사용합니다.
- 챗봇·번역·대응단계·미국/일본 시설·경로·알림·지진/쓰나미는 기존 통합 로직을 유지합니다. 백엔드 코드를 구버전으로 덮어쓰지 않았습니다.
- 원본에 없던 통합 기능의 화면은 integration.css에서 원본 디자인 토큰을 사용하는 연결 스타일로 맞췄습니다.
- production 반응형을 유지하며 /mobile-preview.html의 내부 viewport는 402 × 874로 유지합니다.

검증: 프론트 121개와 실행 관련 4개 테스트 통과 및 프로덕션 빌드 성공. 브라우저에서 원본 소개 화면, 홈, 아이콘 탭, 챗봇 입력창을 확인했습니다. 대화가 비어 있을 때 화면이 자동으로 아래로 이동하던 현상도 수정했습니다. 원본 전체를 그대로 교체한 것은 아닙니다. ZIP의 서비스에는 미국 조회 범위, 예시 좌표, 기존 화면에 없는 경로 변환 등이 있어 해당 서비스로 현재 앱의 실제 기능을 되돌리지 않았습니다.
