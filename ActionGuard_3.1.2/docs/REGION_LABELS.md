# 지역 이름 한국어 병기

2026-10-16. 공식 지역 ID·원문 이름·조회 조건·경보 판정은 유지하고 표시 라벨만 추가했습니다.

- 일본: JMA 관할 58곳, 시·구·정·촌 경보 구역 1,805곳. `도쿄도 (東京都)`, `지요다구 (千代田区)`처럼 표시합니다. 분할 구역은 `요코하마시 북부 (横浜市北部)`처럼 분할을 유지합니다.
- 미국: 50개 주, 워싱턴 D.C., 5개 영토. 코드 입력 대신 `캘리포니아주 · California (CA)`처럼 목록에서 선택합니다.
- 적용: 공식 경보 찾기, 일본 경보 목록/선택 지역, 알림 설정, 시정촌 선택, 저장한 알림 지역, 지역 경보 상세.

## 데이터와 정확성 범위

공식 원본: https://www.jma.go.jp/bosai/common/const/area.json (2026-10-16 목록 확인).

`data/japan-regions-ko.json`에는 원문·JMA 영문 독음·한국어·표기 방식이 있습니다. 관할과 주요 지명은 정리한 표기를 사용하고, 나머지는 JMA 영문 독음→가나→한국어로 만든 표시용 음역입니다. 지역의 공식 한국어 명칭으로 인증된 자료가 아닙니다. 알려진 오독은 원문/코드와 대조해 수정할 수 있습니다. API는 `name`/`code`를 바꾸지 않고 `ko_name`, `display_name`, `label_method`를 추가합니다. 코드가 같아도 원문 이름이 바뀌면 이전 한국어 표기를 재사용하지 않습니다.

음역 생성 과정은 빌드 시에만 수행했습니다(jaconv/Hangulize 사용). 앱 실행과 지역 선택 시 Gemini나 추가 패키지가 필요하지 않습니다. 프론트는 `data/japan-region-display.json`의 작은 표시용 인덱스를 사용합니다. 전체 카탈로그 수정 후 `python tools/build_region_display.py`로 다시 만듭니다.

미국 목록: `data/us-states-ko.json`. 현재 백엔드가 허용하는 56개 코드와 일치하는지 검사합니다. 카운티·기상 예보 구역 전체의 한국어 번역은 이번 변경에 포함하지 않았습니다.

## 검증

한국어와 원문 병기, 일본 전체 카탈로그/프론트 인덱스 일치, 미국 지원 코드 일치, 공식 이름 변경 시 오래된 라벨 미사용, 지역 추가 시 원문/코드 보존, 미국 주 이름 선택을 테스트했습니다. 최종 실행·빌드 결과는 인수인계 시점의 테스트 기록을 확인하세요.

최종 검증: 백엔드 391개·프론트엔드 116개 통과(선택적 백엔드 점검 2개 건너뜀), 배포용 빌드 성공. 실제 JMA 관할/시정촌 API의 원문·한국어 필드를 확인했고, 브라우저에서 도쿄도·지요다구·뉴욕주 선택을 확인했습니다. 실행 화면과 서버의 버전 일치도 확인했습니다.
