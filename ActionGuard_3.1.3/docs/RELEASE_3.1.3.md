# ActionGuard 3.1.3 · 2026-10-19

마지막 기록된 릴리스 3.1.2 이후의 수정 사항을 묶은 공유용 소스입니다.

- 홈·일정·지도의 공통 위치 등록 UI, 버튼, 삭제 동작과 화면 간격을 통일했습니다.
- 일정에는 공통 위치와 별도로 미래 일정의 장소를 선택할 수 있습니다.
- 위치 선택용 지도를 해당 입력 화면 안에서 열고 불필요한 등록 버튼과 문구를 정리했습니다.
- 화산 이름·상태의 한국어 표시, 등록 위치 기준 거리순 정렬과 거리 표시를 개선했습니다.
- AMBER 경보를 아동 납치 경보로 구분하고 차량 식별 정보를 보존하도록 보완했습니다.
- 탭 제목의 왼쪽에 하단 탭과 같은 아이콘을 적용하고 기상 경보 확인 정보 간격을 정리했습니다.
- 같은 서버에서 웹 화면과 API를 제공하는 Docker/Render 구성을 포함합니다.
- 웹/API/iOS/Android 버전은 3.1.3, 네이티브 빌드 번호는 313입니다.
- Gemini 기본 모델은 3.5 Flash-Lite입니다. 3.1 비교 평가 결과는 evaluation/runs/gemini-3.1-vs-3.5/REPORT.md에 포함했습니다. 모델을 하향 적용하지 않았습니다.

키·로컬 환경·개인 서명 설정·설치된 의존성·기기 데이터·빌드 산출물은 제외했습니다. iOS 서명은 사용하는 개발자 계정으로 지정해야 합니다. 앱스토어 업로드용 IPA/APK가 아닌 소스 공유본입니다.
