# ActionGuard Travel 3.1.2 · 2026-10-18

3.1.1 기능을 유지하면서 모바일 정보 순서와 읽기 편의성을 개선한 버전입니다.

## 변경 사항
- 경보 결과는 ‘01 상황 → 02 행동’ 순서로 표시합니다. 추상적인 보호행동 안내 대신 구체적인 공식 행동지시를 우선합니다.
- 등록 위치 적용 여부와 AI 판단 근거는 행동 뒤의 보조 항목으로 옮겼습니다. 적용 여부·조회 실패 등 현재 상태는 접힌 제목에도 표시합니다.
- 행동지침 조회가 실패해도 이미 번역된 공식 지시는 표시합니다. 공식 지시와 일반 행동요령은 구분합니다.
- 시간·지역 핵심 정보는 계속 기본 표시합니다.
- 홈 경보 배지는 우측 상단으로 정렬하고 제목·요약 스타일을 정돈했습니다.
- 일정·지도·AI 질문 바로가기를 간결한 목록으로 묶었습니다.
- 펼침 아이콘을 오른쪽으로 통일하고 열린 상태에서는 방향을 바꿉니다.
- 일정 안내의 반복 문구를 줄이고 입력창을 정리했습니다.
- 준비물 완료 개수·진행 막대를 추가하고 현지어로 잘못 표시되던 안내를 바로잡았습니다.
- 챗봇 추천 질문과 공통 버튼·글자·터치 영역을 정리했습니다.
- 웹/서버 버전 3.1.2, iOS 빌드 312, Android versionCode 312.

## 확인
- 프런트엔드 테스트 174개 통과, TypeScript 검사 및 웹 프로덕션 빌드 성공.
- 402 × 874 CSS 픽셀, 100% 줌의 고정 모바일 미리보기에서 실제 선택 경보로 홈·행동지침·펼침 동작 검토.
- 이전 백엔드 기능 검증 결과는 3.1.1 문서 참고. 이번 변경은 UI 및 버전 표기이며 백엔드 전체 테스트를 새로 실행한 결과가 아닙니다.
- 기존 큰 JS 묶음 경고는 남아 있습니다.
- 실제 iPhone/Android 설치, APNs/FCM 실수신 검증과 운영 환경 구성은 별도입니다. 소스 압축파일은 앱스토어 설치 파일이 아닙니다.
