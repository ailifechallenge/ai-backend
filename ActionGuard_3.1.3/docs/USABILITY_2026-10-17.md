# 사용 흐름 개선 · 2026-10-17

기존 팀 디자인과 모든 기능 진입점을 유지하면서 입력·판단 횟수를 줄였습니다. 과거 문서의 ‘위치·일정은 새로고침 시 사라짐’ 설명은 이번 변경으로 대체합니다.

## 위치와 일정

국가 선택 → 도시·숙소·명소 이름 검색 → 검색 결과 선택 → 지도 확인 → 등록 순서입니다. 지도에서 지점을 조정할 수 있습니다. 도시 검색 결과는 도시 대표점이며 실제 숙소나 현재 GPS 위치와 다릅니다. 좌표 직접 입력은 고급 항목으로 옮겼습니다.

일본은 Asia/Tokyo, 미국은 NWS 좌표 메타데이터에서 시간대를 확인합니다. 미국 시간대 조회 실패 시 추측하지 않고 일정에서 직접 선택하게 합니다. 광역 주 이름만으로 가까운 시설을 확정하지 않습니다.

조회 위치를 바꿔도 이미 저장한 일정은 유지됩니다. 일정 편집 중에는 마지막으로 저장한 일정이 보존되며, 편집한 내용을 저장해야 새 일정으로 바뀝니다.

## 경보 읽기

번역 화면은 ‘무슨 상황인지 → 등록 위치에 해당하는지 → 필요한 행동’ 순서입니다. 원문 근거·번역 검증과 대응 4단계 판단 설명은 펼쳐 볼 수 있습니다. 번역을 사용할 수 없을 때는 기본 행동 카드를 바로 볼 수 있습니다.

미국은 공식 경보 다각형 또는 NWS 좌표 조회 결과로, 일본은 해당 시구정촌 기상 구역으로 적용 범위를 대조합니다. 붙여넣은 문자만으로 위치 적용 여부를 확정하지 않습니다. 만료·목록 불일치·조회 실패는 안전이나 해제로 판단하지 않습니다.

등록 위치의 공식 기상 경보 중 한 건을 우선 표시하고 나머지는 접습니다. 일본 지진·쓰나미는 기존 전용 지도로 별도 확인합니다. 새 조회 기능이 긴급지진속보나 휴대폰 재난문자 자동 수신을 의미하지는 않습니다.

## 기기 저장과 갱신

localStorage의 actionguard-journey-v1에는 등록 위치와 저장한 일정만 저장합니다. 문자 원문, 번역, 대화, 과거 겹침 판정은 저장하지 않습니다. 위치 등록 패널에서 기기 저장 내용을 지울 수 있습니다. 저장을 사용할 수 없는 환경은 화면에 알립니다. 같은 브라우저·같은 서버 주소에서 복원되며 포트가 바뀌면 다른 저장소입니다.

복원한 위치의 공식 기상 경보는 화면 진입·연결 복구·창 재활성화 및 1분 간격으로 재조회합니다. 조회 실패를 ‘경보 없음’으로 표시하지 않습니다. 기상 경보가 없다는 결과도 안전을 뜻하지 않습니다.

## 추가 API

- GET /api/places/search?q=도쿄역&country=JP: 실제 장소 후보와 출처.
- POST /api/places/metadata: ChatLocation → timezone/source/warning.
- POST /api/places/alerts: ChatLocation → Alerts.
- POST /api/places/applicability: Input + location → inside/outside/unknown 및 근거 설명.

장소 검색과 공식 조회는 Gemini 없이 동작합니다. 검색어는 장소 검색 제공자, 좌표는 공식 조회·지도 제공자에 전달되므로 화면에 안내합니다. AI 번역·질의는 기존 서버 설정과 동의 범위를 따릅니다.

## 검증 범위

단위·회귀 테스트에 더해 일본 실제 장소 검색·지도 확인·등록 후 새로고침 복원과 미국 실제 도시 검색·NWS 시간대 확인을 점검했습니다. 실기기 푸시, 현장 시설 개방, 실제 대피 경로 안전성은 이번 검증 범위가 아닙니다.
