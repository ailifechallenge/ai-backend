# 응답 처리 수정 (2026-10-15)

분석 서버가 종료된 상태에서 개발 서버가 빈 오류 응답을 반환하면 JSON 파싱 오류가 표시되던 문제를 수정했습니다. 일반 API와 OCR 요청에 공통 응답 처리 및 시간 제한을 적용했습니다. 서버가 반환한 유효한 오류 설명은 유지하고, 빈 응답과 HTML 오류 페이지는 한국어 안내로 표시합니다.

검증: 프론트엔드 테스트 21개 및 빌드 통과. Desktop 실행본에 API 처리 파일 적용 후 분석 서버 시작, 화면 서버를 경유한 /api/health HTTP 200 및 AI 설정 확인. 실제 모델 생성 요청은 이번 확인에서 실행하지 않았습니다.
