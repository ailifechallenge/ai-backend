# 미국·일본 대응 4단계 — 기본 판정 + AI 해석

문자 이해하기를 누르면 **정보 → 주의 → 대비 → 대피**의 앱 참고 척도를 표시합니다. 미국·일본 정부의 공식 등급 환산이나 현재 위치의 대피 명령 판정이 아닙니다.

## 화면 흐름

1. 원문 기준의 기본 판정을 즉시 표시합니다. 미국 Wind Advisory/Lake Wind Advisory, High Wind Warning과 일본의 주의보·경보·특별경보·위험경보·쓰나미·대피 지시·긴급지진속보 등을 처리합니다.
2. 같은 원문의 대응 행동을 Gemini가 해석하는 동안 기본 단계와 **AI 원문 해석 중**을 표시합니다.
3. AI의 단계·행동·근거 구절을 확인한 뒤 결과를 반영합니다. 새로운 행동 문장·경로·대피소는 AI가 생성하지 않습니다. 화면의 행동 문장은 검토된 안내 템플릿을 사용합니다.
4. AI가 실패하거나 근거가 부족하면 기본 판정을 유지합니다. 기본 판정도 불가능하면 확인 필요로 표시하며 임의로 낮은 단계에 넣지 않습니다.

| 단계 | 의미 | 예시 |
|---|---|---|
| 정보 | 명시된 정보성 발표와 후속 안내 확인 | Special Weather Statement, 地震情報 |
| 주의 | 활동·이동을 조정하고 주의사항 확인 | Wind Advisory, 強風注意報 |
| 대비 | 지금 준비하거나 보호행동 실행 | Tornado Watch, 暴風警報, 津波注意報 |
| 대피 | 재난별 즉시 안전 확보·보호·이동 | Tornado Warning, 津波警報, 避難指示, 緊急地震速報 |

4단계에도 서로 다른 행동이 있습니다. 토네이도는 낮은 층의 창문 없는 실내, 쓰나미는 대상 해안에서 높은 곳·내륙, 긴급지진속보는 머리를 보호하는 등 재난별 안내를 함께 읽어야 합니다. 긴급안전확보·특별경보를 모든 사람에게 밖으로 이동하라는 지시로 바꾸지 않습니다. 일본의 고령자 등 대피 안내는 대상자를 구분합니다.

## 근거 검사와 한계

- AI 근거 구절은 원문 또는 서버에서 확인한 경보명·공식 행동지시에 정확히 존재해야 합니다.
- 인용을 짧게 잘라 조건·부정을 숨기지 않도록 주변 문장도 확인합니다.
- 조건부 대피, 부정문, 취소·시험·만료를 구분합니다. 취소·만료·시험은 AI 호출보다 먼저 확인하고 현재 단계로 강조하지 않습니다.
- 원문으로 확인한 단계는 AI가 임의로 낮추지 못합니다. 4단계나 대피 방식 변경은 지원하는 명시적 경보 또는 직접적인 행동 근거가 있어야 합니다. 풍속·규모·severity 숫자만으로 대피를 만들지 않습니다.
- 위 검사는 보수적인 규칙이며 모든 자연어의 안전성을 보장하지 않습니다. 복합 재난·부분 해제·역사적 인용에는 추가 평가가 필요합니다.
- 실제 발령·현재 유효성·내 위치·이동 경로의 안전성은 이 카드가 확인하지 않습니다. 직접 입력문은 발령 미확인 표시를 유지합니다.

## AI 호출과 데이터

`POST /api/urgency`에 `use_ai:false`를 보내면 기본 판정만, `use_ai:true` 또는 생략 시 AI 보조 판정을 요청합니다. 웹 화면은 기본 판정과 AI 보조 판정을 순서대로 요청합니다.

AI 요청에는 재난문자 원문, 선택 국가, 서버가 확인한 공식 경보명과 공식 행동지시가 Google Gemini로 전송됩니다. API 키는 요청 본문이나 평가 보고서에 넣지 않습니다. 사용자는 문자 이해하기 버튼 근처에서 전송 안내를 확인할 수 있습니다. 동일한 입력·모델의 승인된 결과는 메모리에서 5분 캐시하며 취소·만료 여부는 캐시보다 먼저 검사합니다. AI 해석은 최대 25초를 기다리고 실패하면 기본 판정을 유지하며 자동 재시도하지 않습니다. 기존 무료 티어 확인 및 일일 호출 한도를 그대로 사용합니다.

## 평가

- `backend/tests/test_urgency.py`, `test_urgency_ai.py`: 미국·일본 제목, 자유 형식 지시, 조건·부정·취소·만료, 근거 조작, 단계 임의 하향, AI 실패, 캐시를 검사합니다.
- `frontend/src/pages/Flow.urgency.test.tsx`: AI 대기 중 기본 단계 표시, AI 실패 시 유지, 입력 변경 초기화를 검사합니다.
- `evaluation/urgency_us_jp_cases.json`: 검토용으로 구성한 합성 예문 8건입니다. 실제 수신 문자를 개인정보 제거한 평가집이라고 주장하지 않습니다. 실제 모델 결과는 별도 보고서에 기록합니다.
