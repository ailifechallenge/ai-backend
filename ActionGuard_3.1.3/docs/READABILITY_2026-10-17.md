# 경보 가독성·일정·탭 개선

- 홈의 공식 경보 제목을 경보명으로 표시합니다. Heat Advisory → 폭염 주의보 등 지원 경보명은 한국어로 병기합니다. 모르는 명칭은 원문을 유지합니다.
- 공식 경보 표시 옆에 현재 1~4단계·이름을 보여주고, 홈과 번역 상세에 가로형 정보·주의·대비·대피 척도를 둡니다. 단계는 API의 근거 기반 판정을 사용하며 없으면 미확인, 비활성이면 미표시입니다. 공식 기관의 등급을 뜻하지 않습니다.
- 대응 4단계 상세 카드도 기본으로 펼쳐 보여줍니다.
- 긴 적용 지역은 목록을 접고, 긴 공식 행동지침은 3줄 미리보기와 전체 펼치기로 제공합니다. 상세 행동은 문장별로 나누어 추가 행동을 펼쳐 읽습니다. 원문 지시를 임의로 새로 요약하지 않습니다.
- 하단은 홈·일정·원형 챗봇·지도·대비 순서입니다. 지도는 현재 조회 국가로 이동합니다.
- 공통 조회 지점을 변경하면 선택한 공식 경보·번역·단계와 이전 수동 검색 목록을 비웁니다. 늦게 도착한 예전 번역은 버립니다. 새 위치 경보는 별도 조회합니다.
- 일정 저장이 공통 조회 위치와 선택 경보를 바꾸지 않습니다. 공통 위치와 일정 국가가 다르면 화면에서 구분합니다. 다른 시간대의 장소 선택 시 체류 시간을 다시 입력합니다. 국가 변경 시 옛 좌표와 임의의 미국 기본 시간대를 유지하지 않습니다.
- 저장 비교는 편집 시 무효화되며, 입력 오류·국가/시간대 불일치·시작 종료 역전을 표시합니다. 저장 일정은 기기에 유지하고 과거 겹침 결과는 복원하지 않습니다.

검증: 프론트 회귀 테스트, 백엔드 전체 테스트, 프로덕션 빌드 및 402×874 브라우저 확인. 실제 사용자 저장 일정과 위치는 삭제하지 않았습니다.
