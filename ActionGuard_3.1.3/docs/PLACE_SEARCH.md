# 장소·구매처 검색

## 장소 검색
- 도시 대표점: Open-Meteo/GeoNames. 정확한 이름이 맞는 도시만 후보로 사용합니다.
- 장소·주소: Photon/OpenStreetMap, 결과가 없으면 Nominatim/OpenStreetMap.
- 사용자가 검색 버튼을 누를 때만 조회하고 결과를 캐시합니다. 국가를 제한하며 근거 없는 좌표를 AI로 생성하지 않습니다.
- Nominatim 요청은 서버 프로세스 내 전역 간격 제한(초당 1회 이하), 식별 User-Agent, 결과 캐시를 사용합니다. 여러 서버를 운영할 때는 공유 제한기 또는 별도 검색 인스턴스를 구성해야 합니다.
- 공개 지도에 없는 호텔은 이름으로 나오지 않을 수 있습니다. 공개 지도 색인에서 누락된 Arlo 계열 호텔은 공식 연락처 페이지의 이름·주소를 `data/verified-places.json`에 검토 기록으로 보관합니다. 일치하는 호텔명을 입력하면 앱이 공식 주소를 실제 지도 검색에 보내고, 건물 번호가 일치하는 상세 주소 결과만 호텔 후보로 연결합니다. 좌표를 하드코딩하거나 도시 대표점을 호텔로 대체하지 않습니다. 목록 밖 호텔의 이름 검색까지 보장하지 않습니다.
- 환경변수 `ACTIONGUARD_PHOTON_URL`, `ACTIONGUARD_ADDRESS_SEARCH_URL`로 제공자를 변경할 수 있습니다.

## 구매처
Google Maps의 카테고리 검색 링크를 사용합니다. 현재 위치는 Google Maps의 `near me` 검색, 등록 장소는 확인한 장소명·주소와 국가를 검색어에 넣습니다. 좌표를 텍스트 검색어에 붙이던 방식은 제거했습니다. 앱에서 매장의 재고나 영업을 확인한 것은 아닙니다.

## 확인
GPS를 받은 뒤 새 좌표로 바로 조회하는지, 다른 국가 좌표·취소된 이전 요청이 사용되지 않는지 테스트합니다. 실제 기기 GPS 권한과 Google Maps 현재 위치 정확도는 기기 설정의 영향을 받습니다.
