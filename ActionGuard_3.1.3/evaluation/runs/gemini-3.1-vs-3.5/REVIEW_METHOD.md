# 검토 방법

- 두 모델에 동일한 50개 입력, 동일한 앱 번역 프롬프트·후처리·JSON 스키마, 온도 0을 적용합니다. 각 표본당 1회이며 순서는 표본마다 교대합니다.
- 모델 호출 성공·형식 검증과 의미 정확성을 별도로 봅니다. 형식 검사 통과를 번역 정확도로 표현하지 않습니다.
- 의미 검토 항목: 경보 종류·단계, 지역, 수치·단위, 발령/시작/종료/메시지 만료의 구분, 해제·지속·조건·부정문, 행동 지침의 누락/추가/변경입니다.
- 핵심 의미 오류: 경보 수준 변경, 위험 수치 변경, 조건/부정의 역전, 잘못된 시간 역할, 근거 없는 구체적인 행동 지침입니다. 전체 번역의 항목 누락과 시간대 생략, 지명 읽기, 어색함, 출력 형식 흔적도 별도 기록합니다.
- 요약에는 일부 세부 정보를 생략할 수 있지만 전체 번역에는 원문의 중요 내용을 보존해야 합니다. 별도 행동 지침 번역이 올바르더라도 요약 자체의 왜곡을 상쇄하지 않습니다.
- 검토자는 개발 에이전트 1명입니다. 독립 전문가 검토나 맹검, 확정 정답표에 의한 정확도 인증이 아닙니다. 확인된 오류 사례를 기록하며 '오류 없음'을 안전 보증으로 해석하지 않습니다.
- 미국/일본 각 25건은 공개 발표문·주의보·예보·관측·해제를 포함하며 SMS 표본이 아닙니다. 동일 사건 갱신/형식 차이가 있어 독립 사건 50개가 아닙니다. AMBER·쓰나미·긴급 대피 표본은 없어 해당 유형의 성능을 일반화할 수 없습니다.
- 일본 XML은 원문 텍스트 잎을 순서대로 추출한 입력입니다. 계층·속성의 단위/설명 일부가 없어지는 준비상의 제한이 있습니다. 원본 XML과 별도로 보존하며 이로 인한 애매함을 모델 단독 오류로 단정하지 않습니다. 운영 앱 전체 처리 경로의 평가가 아닙니다.
- 비용은 응답 usageMetadata와 2026-10-19 Google 표준 유료 단가로 환산합니다. 현재 계정에서 실제 청구된 금액이 아닙니다. 서버/OCR/검증/채팅 등 다른 호출 비용은 포함하지 않습니다.
