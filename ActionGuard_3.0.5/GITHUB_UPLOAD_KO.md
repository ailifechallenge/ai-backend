# GitHub 업로드 안내

1. ZIP을 압축 해제합니다.
2. GitHub 저장소에서 Add file → Upload files를 엽니다.
3. 이 폴더 안의 코드 폴더와 파일을 올립니다. ZIP 자체를 올리면 소스가 펼쳐지지 않습니다.
4. 파일이 많아 웹 업로드가 어렵다면 GitHub Desktop에서 저장소를 복제한 뒤 이 폴더의 내용을 복사하고 Commit → Push 하세요.

backend/.env의 실제 키, 가상환경, node_modules, 빌드 산출물, 개인 실행 데이터는 제외했습니다. 실행은 README.md를 확인하세요. 팀원은 .env.example을 복사해 각자 키를 설정해야 합니다.

현재 코드: 팀 원본 디자인 유지 + 모바일 사용성 개선, 미국·일본 경보/지진·쓰나미/AI 도우미/대피시설·길찾기/일정/알림 기능. 최신 태풍 경보 AI 대응 단계 판정 수정과 위치의 주·지역 표시 개선을 포함합니다.

이 파일은 새로 다운로드한 폴더에 압축 해제하세요. 기존 개발 폴더에 덮어쓸 필요가 없습니다.
