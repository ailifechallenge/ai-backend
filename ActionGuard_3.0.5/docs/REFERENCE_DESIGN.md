# 모바일 화면 개편 (2026-10-16)

사용자가 제공한 9개 시안의 카드 구성·화면 밀도·하단 4개 메뉴·긴급 연락 영역을 기준으로 수정했습니다. 기준 앱 뷰포트는 402 × 874 CSS px입니다. `시작.command`는 `/mobile-preview.html`을 엽니다. 작은 창에서는 외부 프레임만 축소하며 앱 내부 크기는 유지합니다.

## 화면과 실제 연결
- `/welcome`: 5개 핵심 사용 흐름과 시작 버튼. 최초 홈 방문에 표시하고 이후 다시 보기 지원.
- `/`: 연결한 실제 경보·번역·공식 행동지시, 일정 비교, 대피시설 진입, 일본 지진·쓰나미, 알림 설정. 경보가 없으면 입력과 조회 안내를 표시합니다.
- `/analyze`: 기존 입력·공식 조회·번역·검증·행동지침·AI 대응단계 유지. 상세 카드와 글자 크기 조정.
- `/response-guide`: 대응 4단계의 의미, 불확실한 경우 처리, 재난에 따른 보호행동 차이 안내.
- `/itinerary`: 기존 위치·체류시간 입력과 실제 경보 겹침 판정 유지.
- `/chat`: 기존 앱 전체 AI 도우미 API 유지. 질문·답변 말풍선 분리, 연결 기능, 답변 근거, 작은 개인정보 안내, 추천 질문과 입력 영역 재배치.
- `/shelters`: 실제 미국·일본 시설·지도·경로 기능 유지. 홈과 AI 도우미에서 진입. 개방·적합성 미확인 표기 유지.
- `/prepare`: 준비물 체크, 국가별 SOS 카드, 사용자 주소, 미리보기.
- `/notifications`, `/japan-disasters`, `/weather-alert`: 기존 기능 유지하며 공통 모바일 스타일 적용.

## 데이터 경계
시안의 Houston 경보·Watch→Warning 변경 이력·여러 일정 카드 등 예시 데이터는 실정보로 넣지 않았습니다. 여러 일정 동시 관리, 자동 경보 재확인, 실제 기기 푸시 수신의 기존 구현 한계도 그대로입니다. 알림·변경 정보는 해당 실제 조회 화면에서 확인합니다. 응급 전화 영역은 선택된 미국/일본 국가를 반영하며 전화 연결은 사용자가 누를 때만 수행합니다.
