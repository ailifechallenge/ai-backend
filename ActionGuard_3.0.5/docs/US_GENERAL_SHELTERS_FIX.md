# 미국 기본 대피시설 검색과 챗봇 수정

기존 바탕화면 버전과 통합본의 Gemini 모델·키 설정 및 기본 챗봇 응답 엔진은 같았습니다. 문제는 검색 데이터 범위였습니다. 미국 일반 검색은 FEMA 운영 중 시설만 조회했고, 뉴욕시 허리케인 지정 접수센터 자료는 hurricane 선택에서만 추가됐습니다. 일본 일반 검색은 피난·체류시설 목록을 조회하므로 같은 질문에서도 결과 양이 달랐습니다.

## 변경
- 뉴욕 지역의 일반 검색에도 지정 접수센터 위치를 참고자료로 함께 표시합니다.
- `Shelter.reference_only`가 true인 자료는 허리케인 전용·개방 미확인임을 표시하고 일반 대피소나 입소 목적지로 취급하지 않습니다.
- 참고자료 ID는 `ref:`로 구분하고 직접 경로 API에서도 목적지로 승인되지 않습니다. 허리케인 검색 결과와 캐시가 섞이지 않습니다.
- 홍수·토네이도 등 다른 재난의 전용 검색에는 허리케인 자료를 추가하지 않습니다.
- 챗봇은 운영정보와 지정시설 참고자료를 나눠 설명하며, 시설명·직선거리·공식 출처와 지도 연결을 제공합니다.
- FEMA 조회 실패를 운영 시설 부재로 표시하지 않습니다.

현재 추가 지정시설 카탈로그는 뉴욕시 자료입니다. 미국 전역의 모든 지정시설을 확보한 것은 아닙니다. 지정 위치와 현재 개방 여부는 다릅니다. 공식 안내: https://www.nyc.gov/site/em/ready/hurricane-evacuation.page

검증: 백엔드 411개 통과·2개 건너뜀, 프론트엔드 121개 통과, 빌드 통과.
