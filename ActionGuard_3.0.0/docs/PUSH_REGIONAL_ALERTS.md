# 등록 지역·재난별 경보 알림 (2026-10-15)

## 이번에 연결한 범위

- 기존 일본 지진 관측 진도·쓰나미 예보구 구독에 미국 NWS / 일본 JMA 기상경보 구독 추가.
- 미국: 주 전체가 아니라 NWS 카운티(C)·예보구(Z) UGC를 선택. 위치에 맞는 두 종류 구역을 함께 선택할 수 있음. 폴리곤 경보도 해당 구역 일부만 적용할 수 있으므로 구역 일치는 현재 위치 위험 확정이 아님.
- 일본 기상: 공식 관할(office) + 시정촌(class20) 코드. 지진 도도부현 및 쓰나미 해안 예보구와 별도.
- 유형: 호우, 홍수, 강풍, 뇌우·토네이도, 눈·눈보라, 폭염, 한파·서리, 파랑·해일, 산사태, 산불 위험, 안개, 기타. 원문 이벤트 명칭을 규칙으로 분류하며 모르는 유형은 `other`를 선택한 경우만 포함. USGS 미국 지진 등 새 데이터 공급원은 포함하지 않음.

## 알림 정책

1. 최초 구독의 현재 유효한 기상경보는 `current` (현재 유효한 경보). 이미 진행 중인 경보를 새 발령으로 표현하지 않음.
2. 이후 새 발령 `new`, 연결된 경보 단계/심각도 상승 `escalated`, 지역·발효/시작/종료/만료·지시·설명·지도 범위 변경 `changed`.
3. 발표시각/ID만 변경된 동일 내용은 다시 보내지 않음. 일본은 시정촌별 재난 유형의 최고 단계를 비교하여 무관한 지역 갱신을 제외.
4. 공식 취소(NWS CAP Cancel), 일본 시정촌의 최신 완전 상태에서 해제/경보 없음은 `cleared`. NWS 목록에서 사라진 것만으로 공식 해제를 만들지 않음.
5. 기존에 추적하던 미국 경보의 유효시간 종료는 `expired`로 별도 안내. 안전 또는 공식 해제를 의미하지 않음.
6. 원본 조회 실패·필수 항목 누락·미지 코드·지역 누락·일본 발표시각 역행 시 해당 지역 기준 상태를 보존. 발송 대기 항목도 보류하고 다음 조회 대기. 보류는 제공자 발송 시도 횟수에 포함하지 않음. 10분 TTL이 지나면 만료.
7. 구독 변경 시 기존 지역/유형 대기 알림 취소. 각 지역 조회는 작업당 한 번만 수행. 기기별 선택 및 dry_run/live 별 중복 키를 분리.
8. 알림을 누르면 외부 경로가 아닌 `/weather-alert`에서 해당 지역 최신 공식 상태 재조회. 과거 알림을 현재 경보로 복원하지 않음. 원문 → 한국어 이해하기로 연결. 현재 목록에 없는 과거 알림은 갱신/부재를 명시.

## API / 구독 형식

기존 등록·변경 API의 `preferences`에 다음 필드 추가. 기존 지진/쓰나미 구독은 호환 유지.

```json
{
  "prefectures": [],
  "tsunami_regions": [],
  "seismic_hazards": [],
  "minimum_intensity": "3",
  "weather_regions": ["US:CA:CAZ522", "JP:130000:1310100"],
  "weather_hazards": ["wind", "flood", "rain"]
}
```

- `weather_regions`: 최대 10개, 중복 정리. 실제 공식 지역 목록에 있는지 등록/변경 때 서버가 검증.
- `weather_hazards`: 적어도 하나; 지역과 유형을 함께 선택. `other`까지 강제 구독하지 않음.
- `seismic_hazards`: earthquake, tsunami 중 선택. 기존 클라이언트 미지정 시 두 유형 유지.
- `GET /api/push/regions?country=US&region=CA`: 카운티/예보구 목록.
- `GET /api/push/regions?country=JP&region=130000`: 시정촌 목록.
- `GET /api/push/hazards`: 기상 재난 유형.
- `GET /api/push/weather?scope=JP:130000:1310100`: 구역 최신 경보. 조회 실패를 빈 성공 응답으로 바꾸지 않음.
- 상태 API는 US/JP/weather 범위 및 `weather_health`의 조회 지역 수·실패 지역 수만 공개. 기기 토큰이나 등록 지역 목록은 노출하지 않음.

## 현재 실행과 남은 연결

기본은 disabled. 모의 실행은 실제 전송 없이 `previewed`만 기록한다. APNs/FCM 제공자 자격증명과 실제 휴대폰 수신 검증은 여전히 별도다.

알림 화면의 지역/유형 편집기는 **브라우저에 선택을 저장하는 초안**이며 서버 구독 활성화를 주장하지 않는다. 기존 네이티브 앱은 아직 토큰·기기별 관리 키를 안전하게 영속 저장하고 위 등록/변경 API와 자동 연결하는 과정이 남았다. 이 단계를 완료하기 전에는 실제 사용자에게 푸시가 켜졌다고 표시하면 안 된다.

현재 작업자는 60초 폴링, 지역 조회 캐시 60초의 파일럿 구조다. 대규모 구독에 대한 처리량·제공자 한도·가용성 측정은 미완료다. 기상 조회는 지역별 실패를 분리하지만 지진·쓰나미 공통 소스 검증 실패 시 현재 실행 전체가 보수적으로 중단되는 제한도 있다. 지진 긴급속보(EEW)나 지연 없는 경보 전달을 보장하지 않는다.
