# AI 도우미 장소 인식 수정

- 원인: 등록된 지명 외에는 “에서·주변·근처” 같은 표현이 있어야 장소 해석을 시도하여, “에 있는데” 문장을 누락했습니다. 프론트엔드 롤백은 아니었습니다.
- 장소 표현: 에 있는데·살고·거주·머무는 등 문맥을 인식하고 모델 응답이 실패해도 원문에 실제 적힌 장소는 지도 검색 입력으로 유지합니다. 좌표를 모델이 생성하지 않습니다.
- 랜드마크: 실제 POI 검색을 사용하고 정확한 이름의 결과를 우선합니다. 자유의 여신상과 매표소를 혼동하지 않습니다.
- 넓은 지역: 미국 주 이름은 가까운 시설의 기준점으로 바꾸지 않고 도시·동네를 되묻습니다.
- 후속 대화: 도시명만 답해도 이전 조회 의도를 이어가며, 검색 실패 후 재시도도 사용자가 말한 장소를 다시 사용합니다.
- 실패: 지도 검색 실패를 “위치를 알려 달라”는 답변으로 바꾸지 않고, 알아들은 장소와 조회 실패를 표시합니다.
- 화면: 위치가 필요하지 않은 답변을 받으면 불필요한 위치 입력 패널을 닫습니다.

검증: 회귀 사례 16개 추가, 전체 백엔드 407개 통과·2개 건너뜀, 프론트엔드 120개 통과, 빌드 통과. 실제 지도 검색에서 자유의 여신상의 POI 결과를 확인했습니다. 시설·경로의 현재 안전성을 보장하는 시험은 아닙니다.

추가로 AI 도우미의 시설 지도 링크에 포함된 검색 좌표를 지도 화면이 무시하던 문제를 수정했습니다. 전달된 좌표로 실제 검색 요청이 나가는지 회귀 테스트를 추가했습니다.
