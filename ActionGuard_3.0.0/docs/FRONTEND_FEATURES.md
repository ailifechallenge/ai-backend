# 프론트엔드 팀용 기능 요약

2026-10-16 현재 구현 기준. 상세 API·파일·상태는 [인수인계 가이드](FRONTEND_HANDOFF.md), 기계 판독 스키마는 [API 스키마](FRONTEND_API_SCHEMA.json)를 참고하세요.

## 핵심 사용 흐름

받은 문자 입력/공식 경보 선택 → 한국어 핵심 요약 → 실제 번역 오류만 확인 → 대응 단계·행동지침 → 필요하면 일정 비교·AI 질문·주변 시설·길찾기.

## 화면에 연결할 기능

| 기능 | 지금 구현된 것 |
|---|---|
| 문자 이해(F1) | 텍스트·이미지 OCR, 미국·일본 공식 경보 조회, 짧은 한국어 요약/해설, 전체 번역 접기, 화씨·섭씨 및 mph·km/h 병기 |
| 자동 검증(F2) | 원문·번역·요약의 날짜/시각 역할/지역/단위/부정/조건 불일치 확인. 독립 탭 없이 중요한 오류만 짧게 표시 |
| 행동지침(F3) | 한국어 공식 지시 + 출처·적용 조건이 있는 일반 안전수칙. 둘의 성격을 구분 |
| 대응 4단계 | 정보·주의·대비·대피, 판정 불가 시 확인 필요. 규칙 기본값에 근거가 확인된 AI 해석 보조 |
| 내 일정 | 장소 한 곳과 체류 시간을 선택한 공식 경보의 지역·시간에 비교 |
| 앱 AI 도우미 | 경보 입력 전에도 사용. 번역·경보·안전수칙·대피소·길찾기·일정·알림 안내. 도쿄역/시카고 같은 장소 질문·복수 후보 선택·후속 위치 질문 지원 |
| 대피시설(F4) | 미국·일본 공식 자료 기반 목록/지도, 재난별 적합성 필터, 거리/시설 상태/출처 표시 |
| 일반 길찾기 | 시설 선택 후 같은 지도 흐름에서 도보/자동차 경로, 현재 구간·이전/다음·원하는 구간부터 보기·한국어 읽기·화면 내 GPS 안내 |
| 일본 지진 | 실제 관측의 진앙·발생 시각·규모·깊이·최대 진도, 진앙 거리, 관측소 지도. 챗봇에서도 구체적인 사건 정보로 답변 |
| 일본 쓰나미 | 현재 유효/해제/과거 발표 구분, 해안별 색상·단계·높이·도달 정보 |
| 지역 알림 기반 | 지역·재난별 새 경보/격상/중요 변경/공식 해제 판별 서버. 브라우저 설정 초안과 현재 상태 화면 |
| 앱 기반 | Capacitor iOS/Android 프로젝트, 알림 수신/탭 이동/딥링크 구조 |
| 지역 이름 | 일본 한국어+원문 병기(관할 58, 시정촌 경보 구역 1,805). 미국 한국어·영문·코드 선택(주/특별구/영토 56) |
| 오프라인 목록 | 시설 목록·약도 저장/불러오기/삭제와 안내 파일 다운로드 |

## 프론트 디자인에서 유지할 기준

- 핵심 요약과 행동을 먼저, 긴 원문·전체 번역·근거는 접어서 표시.
- 조회 실패·확인 필요·경보 없음·공식 해제·메시지 만료는 다른 상태.
- 한국어 지명은 표시용. 조회/저장/구독에는 원래 공식 이름과 코드를 사용.
- 등록 위치·도시 대표 지점·현재 GPS를 구분하고, 출처·확인 시각·시설 개방 미확인을 표시.
- 대피시설 목록과 경로를 한 흐름으로 연결. 대응 4단계의 숫자/색만으로 행동을 결정하지 않기.

## 아직 완성된 기능으로 표시하면 안 되는 것

휴대폰 재난문자 자동 읽기, 실제 기기의 푸시 구독·수신 완성, APK/IPA 배포, 백그라운드 내비게이션, 재난/통제 회피를 보장하는 안전 경로, 내 위치 예상 진도·침수·대피 필요성 자동 판단, 여러 여행 일정/동선 분석은 미완료입니다.

새 UI로 교체할 수 있습니다. 현재 API와 공통 상태의 의미를 유지하고, 실제 사용/실기기/실제 모델 평가 후 출시 여부를 결정해야 합니다.

## 미국 기본 검색 보완

일반 검색에서도 뉴욕시 허리케인 지정 접수센터를 참고자료로 확인할 수 있습니다. 운영 중 일반 대피소와 구분하며, `reference_only=true`인 자료는 입소 목적지로 연결하지 않습니다. 최신 검증은 백엔드 411개·프론트엔드 121개 통과입니다. 자세한 비교와 범위는 [미국 기본 검색 수정](US_GENERAL_SHELTERS_FIX.md)을 참고하세요.
