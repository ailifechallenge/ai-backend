# 2.8 팀 시안 적용 및 통합 길찾기

파란색 주요 동작, 옅은 파란 배경, 흰 카드, 휴대폰 하단 홈·일정·챗봇·대피 메뉴를 기존 데이터에 연결했습니다. 카드 링크의 글자색이 주요 버튼 배경과 같아지는 CSS 충돌을 수정했습니다.

대피소 목록 → 시설 상세 → 경로 안내 → 목록 복귀를 대피 메뉴 안에서 처리합니다. 목록 복귀 시 기존 검색 결과와 선택 시설을 유지합니다. 기존 /navigation 주소도 통합 화면으로 연결합니다.

길찾기는 전체 경로 거리·예상 시간, 큰 방향 아이콘과 현재 구간, 이전·다음 구간, 원하는 구간부터 보기, 현재 안내 음성 읽기를 제공합니다. 경로 조회 후 좌표 입력 영역을 접고 안내 카드로 이동합니다.

‘내 위치로 구간 따라가기’를 누른 경우에만 브라우저 위치 권한을 요청합니다. OSRM 구간 좌표와 GPS를 화면 안에서 비교하고 현재 위치를 지도에 표시합니다. 위치 오차 35m 초과, 경로에서 45m 초과, 서로 겹치는 비인접 구간, 오래된 신호에서는 구간을 추정하지 않습니다. 다른 구간을 수동 선택하면 GPS 따라가기를 멈춥니다. 화면을 나가거나 경로를 바꾸면 추적을 해제합니다.

## 한계와 미구현 범위

일반 도로 경로 미리보기와 화면이 켜진 동안의 위치 기반 구간 안내입니다. 네이버지도·Google Maps와 동등한 검증된 내비게이션이 아닙니다. 백그라운드 안내, 자동 경로 재탐색, 실시간 도로 통제, 재난 위험 회피, 도착 인증, 고도·계단·실내 층별 안내는 제공하지 않습니다. 길을 벗어나면 안전한 곳에서 출발지를 현재 위치로 다시 설정하고 조회해야 합니다. 운전 중 화면을 조작하지 마세요.

시안 속 경보 변경 추적, 다중 일정 비교, 한국식 긴급도 환산, 준비물·SOS 카드는 이 변경의 구현 범위에 포함하지 않았습니다. 실제 데이터 없이 시연 값을 운영 결과처럼 표시하지 않습니다. 기존 일정 한 건 비교·챗봇은 각각 독립 메뉴에서 쓸 수 있습니다.

## 검증

백엔드 154개·프론트엔드 42개 자동 테스트와 배포 빌드 통과. 구간 중간 재개, 부정확한 GPS, 경로 이탈, 겹치는 경로, 추적 정리, 구간 좌표 검증을 포함합니다. 휴대폰 390px 화면에서 하단 메뉴·일정 폼을 확인했습니다. 실제 GPS 이동·차량 주행 현장 검증은 하지 않았습니다. 정식 출시 전 실제 기기·교차로·지하·위치 권한 거절·화면 잠금 상황에서 별도 검증이 필요합니다.
