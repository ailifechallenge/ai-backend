# F4 지도·길찾기 통합 (2026-10-15)

제공된 ActionGuard Travel 2.5 압축본의 F4 모듈만 기존 개선본에 통합했습니다. 기존 미국·일본 경보, 짧은 번역, 단위 보정, 내부 검증, 행동 안내, 챗봇과 일정 겹침 기능은 유지했습니다.

## 사용
- 대피소 지도에서 현재 위치 또는 지도 클릭·좌표 입력으로 검색합니다. 기본 좌표는 뉴욕 예시이며 실제 현재 위치가 아닙니다.
- FEMA 운영 자료와 뉴욕 허리케인 접수센터를 표시합니다. 미국 자료만 지원하며 일본 시설은 미연결입니다.
- 등록 이력은 기본 제외합니다. CLOSED·FULL·미확인 시설은 선택해도 입소 목적지로 연결하지 않습니다. 접수센터는 현장 개방 확인 필요로 표시합니다.
- 건물 유형을 모른다는 이유만으로 공식 시설을 숨기지 않도록 수정했습니다.
- 시설 선택 후 길찾기로 출발·도착 좌표를 넘깁니다. 도보 거리·시간·한국어 구간 안내와 Google Maps 열기를 제공합니다.
- 좌표 기반 지도·도보 조회에는 별도 API 키가 필요하지 않습니다. 앱 내 주소 검색·자동차 계산·Google 비교는 선택적인 Google Routes API 설정이 필요합니다. 서버의 GOOGLE_MAPS_API_KEY로 설정하면 반복 입력하지 않아도 됩니다. Google 지도 표시는 별도의 웹사이트 제한 브라우저 키가 필요합니다. 실제 Google 유료 호출은 이번 작업에서 하지 않았습니다.
- 목록·약도를 명시적으로 저장하거나 HTML 안내 파일로 내려받을 수 있습니다. 다운로드한 HTML은 인터넷 없이 열립니다. 앱 전체의 오프라인 재실행이나 배경 타일 저장은 이번 통합 범위가 아닙니다. 저장본에서 길찾기를 쓰려면 최신 조회가 필요합니다.

## 검증
백엔드 140개, 프론트엔드 34개 통과. 작업본과 Desktop 실행본 빌드 통과. 지도는 필요할 때만 로드합니다.
실제 API: 뉴욕 10km에서 접수센터 20곳(운영 중으로 확인된 FEMA 시설 0곳), 경고 없이 응답. 예시 도보 경로 1,056m, 846.5초 반환. docs/F4_INTEGRATION_LIVE.json에 기록했습니다.
실제 브라우저: 약 340px 폭에서 지도 로드, 목록 선택, 좌표 전달, 선택 시설까지 1.71km·약 23분 경로와 한국어 구간 안내 표시를 확인했습니다. Google 키·유료 경로는 모의 테스트로만 확인했습니다.

## 실행 상태
Desktop 관련 파일만 갱신했으며 이전 파일은 작업 폴더 work/desktop-before-f4에 보관했습니다. .env는 변경하지 않았습니다. 기존 8000 서버의 종료가 환경 권한으로 제한되어 새 통합 서버는 8001, 화면은 5173에서 실행했습니다. 시작.command는 이전 버전 서버를 감지해 통합 서버 포트를 선택합니다. 일반 신규 실행은 8000을 사용합니다.

## 운영 전 확인할 점
공식 자료의 상태가 현장 입소 가능·안전한 대피 경로를 보장하지 않습니다. 경로는 재난·침수·통제를 회피하지 않습니다. 공개 도보 서버는 프로세스당 초당 1회 제한과 캐시를 적용했으며, 다중 서버·대규모 운영은 별도 경로 공급자가 필요합니다.
