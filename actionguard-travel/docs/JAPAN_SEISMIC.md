# 일본 지진·쓰나미 지도

2026-10-15 구현. Gemini 키와 Google Maps API 없이 동작한다.
홈의 **일본 지진 · 쓰나미 지도** → `/japan-disasters`에서 확인한다.

## 제공 기능
- JMA 공개 목록의 최신 30개 지진: 발생/발표 시각, 진앙 지역, 규모, 최대 관측 진도, 진원 깊이.
- Leaflet / OpenStreetMap 지도: 진앙 ×, 공식 관측소 좌표의 진도 색상과 범례.
- 이용자가 위치를 허용하면 진앙까지 Haversine 직선거리 계산. 위치는 앱 서버에 전송하지 않고 화면 상태에서만 관리한다. 지도 타일 조회는 OSM에 요청한다.
- 현재 위치의 정확한 진도/예측 진도는 제공하지 않는다. 20 km 이내 가장 가까운 **발표 관측소**의 해당 지진 당시 진도와 관측소까지의 거리를 별도로 표시한다. 20 km는 앱의 표시 범위이며 과학적인 동일 진도 보장 기준이 아니다.
- 일본 해안 경계를 JMA 예보구 코드와 연결: 대쓰나미 경보(보라), 경보(빨강), 주의보(노랑), 해수면 변동 예보(파랑). 높이/도달 시각은 공식 자료가 있는 경우만 표시한다.
- 과거 쓰나미 발표는 기본적으로 색칠하지 않는다. 사용자가 별도로 열면 지도의 고정 배지에 과거임을 표시한다.
- 화면이 활성화된 동안 60초 주기 조회, 서버 30초 캐시. 지리 경계는 1일 캐시.

## 현재성 / 실패 처리
JMA `clearweb.json`의 `w`보다 늦은 발표만 현재 후보로 취급한다. `ValidDateTime`이 있으면 만료 여부도 검사한다. JMA 시간대 없는 clearweb 시각은 JST로 해석한다. 최신 VTSE41 발표를 사용하며 뒤에 온 관측 메시지가 경보를 덮어쓰지 않도록 종류별 필터를 먼저 적용한다.
같은 사건의 취소·정정을 보존하고 훈련 파일을 제외한다. detail은 공식 목록의 파일명만 허용하여 임의 주소 요청을 막는다. 현재성 확인 실패는 502이며 “경보 없음”으로 바꾸지 않는다. 화면에서도 2분 이상 지난 상태/재조회 오류는 현재 색상을 표시하지 않는다.
지명은 로컬 용어표로 표시용 풀이를 제공하며 원문과 원자료 링크를 유지한다. 미등록 지명은 원문을 유지한다.

## API
- GET `/api/japan/earthquakes`: events, checked_at
- GET `/api/japan/earthquakes/{공식파일명}`: 진앙과 stations
- GET `/api/japan/tsunami`: bulletin, status, checked_at, clear_at
- GET `/api/japan/tsunami-coasts`: JMA 해안 GeoJSON

## 공식 자료 / 운영 한계
- https://www.jma.go.jp/bosai/quake/data/list.json
- https://www.jma.go.jp/bosai/tsunami/data/list.json
- https://www.jma.go.jp/bosai/tsunami/data/clearweb.json
- https://www.jma.go.jp/bosai/common/const/geojson/tsunami.json
- https://www.jma.go.jp/bosai/map.html (실제 사이트의 데이터 선택/clearweb 처리 확인)
- https://www.data.jma.go.jp/eqev/data/tsunami/kaizen/denbun_henkou_online_besshi2_1.pdf (쓰나미 단계 코드)

JMA 웹 공개 자료를 조회하는 기능이다. 보장된 배신 서비스, 초 단위 긴급지진속보, 백그라운드 푸시, 휴대폰 재난문자 자동 수신이 아니다. 현재 미국 USGS 진도 분포/진앙 지도는 이 기능에 포함되지 않는다. 해당 기능을 확장할 때 일본 JMA 진도와 미국 MMI를 섞어 표시하지 않아야 한다.
출시 전 공식 데이터 형식 변경 모니터링, 데이터 이용 조건/출처 표시 및 트래픽 규모에 적합한 지도 타일 공급자, 실기기 GPS 정확도·권한 거부 검증이 필요하다. 진도는 거리·규모만으로 계산하지 않는다.

## 검증
- 일본 기상청 실제 목록/상세/쓰나미/해안 응답 연동 확인. 최신 지바현 북서부 관측 7개 지점, 예시 도쿄역에서 진앙까지 31.4 km, 가까운 발표 관측소까지 1.2 km 확인(테스트 당시 자료).
- 만료된 10월 10일 쓰나미 예보가 현재 경보에서 제외되고 과거 보기에서만 해안 표시되는 것 확인.
- 자동 테스트: 좌표/깊이 누락, 국제 날짜 변경선 거리, JMA 5약/5강, 관측소 누락, 취소/정정, 훈련 제외, 단계 코드, 만료/clearweb, 통신 실패, 임의 상세 URL 거부, 관측 메시지로 인한 경보 누락, 화면 캐시 만료와 과거 지도 토글.

최종 검증: 백엔드 181개·프론트엔드 56개 테스트와 배포용 빌드가 통과했다. 모바일 너비에서 지진 지도, 예시 위치 비교, 과거 쓰나미 표시 전환을 확인했다. 사용자 GPS를 수집하지 않고 공개 지점인 도쿄역으로 비교했다.

현재 실행 주소: http://127.0.0.1:5180/japan-disasters (백엔드 8006). 이전 5179 실행본과 구분한다.

## 다음 단계: 행동요령 → 시설 → 길찾기 연결

- 지진 화면에 JMA 일반 행동요령의 한국어 요약과 원문 근거를 연결했다. 과거 지진을 선택했다는 이유만으로 현재 대피를 명령하지 않는다.
- 쓰나미는 현재 유효한 발표에서 이용자가 해안을 직접 고르면 그 해안의 경보·주의보에 맞는 일반 행동요령을 표시한다. GPS로 해안 경보 해당 여부를 추정하지 않는다. 미선택·예보·과거·조회 실패에는 일반 대비 정보만 표시한다.
- 재난별 지정 대피장소 찾기 버튼으로 일본/지진 또는 일본/쓰나미 검색 조건을 넘긴다. 위치는 확인 시각이 10분 이내인 일본 범위의 GPS나 명시적 도쿄역 예시만 전달한다. 진앙 좌표는 조회 출발지로 사용하지 않는다.
- 위치는 URL에 넣지 않고 React Router 이동 상태로 전달한다. 브라우저 이동 기록 상태에 포함될 수 있다. 자동 조회는 하지 않으며 이용자가 시설 검색을 눌렀을 때 기존 시설 검색 API에 좌표가 전송된다.
- 위치가 없거나 오래된 경우 위치 확인을 안내한다. 예시 좌표는 예시임을 표시한다. 대피소·길찾기에서 선택했던 지진·쓰나미 정보로 돌아갈 수 있다.
- 이 단계에 푸시 알림이나 백그라운드 경보 수신은 포함하지 않는다.

행동요령 근거:
- https://www.jma.go.jp/jma/kishou/know/jishin/eew/koudou/koudou.html
- https://www.jma.go.jp/jma/kishou/know/jishin/joho/tsunamiinfo.html

연결 단계 최종 검증: 프론트엔드 전체 67개 테스트 및 배포 빌드 통과. GPS 시각·오차 보존, 오래된 위치 재사용 방지, 해안 직접 선택에 따른 행동요령 전환을 포함한다. 실제 브라우저에서 도쿄역 예시 → 지진 지정 장소 81곳 조회 → 시설 선택 → 길찾기 화면의 원래 지진 복귀 링크를 확인했다. 길찾기 경로 계산 방식은 변경하지 않았다.
