# 2.9 작업 중심 UX 개편

색상 변경에서 벗어나 화면별 책임을 분리했습니다.

- 홈 첫 화면: 받은 문자 입력과 분석 한 가지 작업. 공통 위치·일정 폼·챗봇을 제거하고 보조 조회는 탭으로 분리.
- 분석 후: 핵심 해설·요약 → 행동지침 → 일정·질문·시설 선택. 입력과 전체 번역·검증·상세 근거는 접어서 표시. 추가 행동은 펼쳐서 확인하며 원문 조건과 금지 표현을 재작성하지 않음.
- 일정: 문자가 없으면 먼저 입력 안내. 위치는 지도·현재 위치로 등록하고 등록한 위치의 좌표는 접음. 체류 시간은 현지 시간대로 입력.
- 챗봇: 문자 없는 상태에 비활성 폼 대신 시작 안내. 같은 문자와 결과를 유지하며 홈과 이동.
- 대피: 검색 조건·좌표·오프라인 관리 기능을 접어 두고 필요할 때 펼침. 결과 조회 후 설정 영역 접힘.

실패 보완: ‘This is not a drill / 訓練ではありません’를 실제 훈련으로 오인하던 위험 상태 규칙 수정. 같은 공통 위치를 재적용할 때 일정이 지워지는 문제 수정. 일반 조회 대기 제한을 45초로 분리하고 AI 비교는 별도 제한 유지. 필수 응답 필드 누락은 렌더링 전에 오류 안내. 검증 불가를 홈에서 명시.

검증: 백엔드 157개·프론트엔드 47개 자동 검사, 빌드, 모바일 390px 홈·실제 미국 표본 결과 확인. 미국/일본 공개 발췌 2건 각 1회 실모델 평가(8요청) 완료. 미국 표본을 실제 앱 화면에서도 확인(4요청, 이후 캐시 재사용). 두 평가 모두 번역 핵심은 1차 개발자 대조에서 보존됐지만 시각 근거 추출 일부는 검증 불가. 독립 평가나 출시 인증이 아님.

20개 표본 정답은 검토 초안이며 독립 검토가 필요합니다. 실제 사용자 과제, GPS 현장 이동 및 운영 용량 점검은 미실시입니다. 실사용 체크리스트에 미실시를 명확히 기록했습니다. 토스 스타일을 참고한 정보 구조와 조작 단순화이며, 토스의 공식 디자인이나 동일 제품을 복제한 것은 아닙니다.
