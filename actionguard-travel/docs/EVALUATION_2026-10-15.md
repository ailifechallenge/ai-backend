합성 표본은 ISO 시각, 날짜/온도 혼동, 복합 재난, 경보 해제, 훈련, 자정, 섭씨/m/s, 미국 일광절약시간 오프셋을 다룹니다. 표본별 정답과 출처는 evaluation/cases.json에 있습니다. 정답은 에이전트의 개발용 1차 검토이며 독립 전문가 승인 전입니다.

네트워크 제한 해제 전 실행은 0건 완료 후 연결 실패했습니다. 네트워크 해제 후 8회 분석 시도 중 5회 완료했습니다. API 오류 2회와 한도 중단 1회를 성공 분모에서 숨기지 않습니다. 429 이후 자동 재시도나 유료 모델 전환을 하지 않았습니다.

개발 에이전트의 출력 점검에서는 완료된 5개 요약에 날짜·단위·부정의 명백한 반전은 발견하지 못했습니다. 다만 파랑 경보의 “지속 중”이라는 표현은 발표 당시 상태와 현재 상태를 혼동하게 할 수 있고, 다른 실행에는 일본어 상태 표현이 남았습니다. 이는 아래 프롬프트 보완에 반영했습니다. 수치화된 정식 요약 오류율 대신 원본 출력과 검토 필요 사항을 남깁니다.

## 발견해서 고친 문제

1. **읽기 어려운 시간:** ISO 시각을 원래 오프셋 그대로 한국어 날짜·오전/오후로 표시합니다. 예: `2026-10-14T16:20:00+09:00` → `2026년 10월 14일 오후 4시 20분 (UTC+09:00)`. 브라우저/서버 지역 시간으로 몰래 바꾸지 않습니다.
2. **시간대 표기 오탐:** 실제 출력의 `(UTC+9)`와 `(+09:00)`도 날짜·시각·오프셋이 같은지 계산해 인정합니다. 시간대가 다른데 시계 숫자만 같다고 통과시키지 않습니다.
3. **발령과 시작 혼동:** 일본 보고 시각을 effective로 채우지 않습니다. 시작·종료 미상은 미상으로 유지합니다. 검증 종류에도 발표와 메시지 만료를 별도로 추가하고, NWS onset이 없을 때 effective를 재난 시작으로 간주하던 대체 처리를 제거했습니다.
4. **일본 경보 갱신:** 시정촌의 최신 상태 묶음을 기준으로 처리해, 코드 없는 전체 해제가 이전 경보를 남기지 않게 했습니다. ID는 원문 버전을 포함해 갱신 시 이전 원문 연결과 혼동하지 않습니다.
5. **부정문 필터:** 문장에 'not'이 있다는 이유로 모든 행동요령을 제거하지 않습니다. 재난별 언급/위험 없음/해제/조건/훈련/불명확 상태와 근거 문장을 구분합니다. 지진 발생 + 쓰나미 우려 없음에서는 지진 안내를 유지하고 쓰나미 안내는 제외합니다. 규칙 기반 초기 버전이며 임의 문장의 의미를 완벽히 판정하지는 못합니다.
6. **행동지침 근거:** 일본 지진과 쓰나미를 별도 카드로 분리했습니다. 일본의 장문 일반 안내를 출처에서 확인 가능한 핵심 행동으로 줄이고 일반 기상 소개 링크를 재난별 설명으로 교체했습니다. 강풍 전 준비를 강풍이 부는 동안 야외에서 실행하도록 읽히지 않게 조건을 명시했습니다.
7. **응답 구조 안정화:** JSON 형식을 프롬프트에만 요청하던 방식에 API의 `responseJsonSchema` 전달을 추가했습니다. 근거: [Google API 문서](https://ai.google.dev/api/generate-content#v1beta.GenerationConfig). 서버의 출력 검증과 실패 시 중단은 유지합니다.
8. **평가 증거 보존:** 평가 도구는 이후 실행부터 코드 해시, 실패 단계 및 실패 전 생성된 번역을 저장합니다. 키·요청 헤더는 저장하지 않습니다.

시간대 동등 비교, 시간 역할 추가, 명시적 JSON 스키마, 일본어 상태 프롬프트 보완은 실모델 평가 이후 수정입니다. 자동 회귀 검사는 통과했지만, 429 이후 실제 모델로 재검증하지 않았습니다. `evaluation/evaluated-code-sha256.json`과 최종 코드가 일부 다른 이유입니다.
