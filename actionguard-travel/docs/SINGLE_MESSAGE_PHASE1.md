# 문자 한 건 이해하기 — 1차 구현

## 이번 범위

받은 문자 붙여넣기 → 한국어 요약/번역 → 표시 내용 대조 → 행동지침 흐름을 보강했습니다. 위치 연계·자동 알림 확장은 이번 변경에 포함하지 않았습니다.

- 붙여넣기 입력에 미국 / 일본 / 모르겠어요 선택을 추가했습니다. 기본값은 모르겠어요입니다. 공식 경보 선택 시 연결된 출처가 국가를 결정합니다. 언어만으로 국가를 추정하지 않습니다.
- 전체 번역뿐 아니라 요약, 해설, 공식 행동지시 번역, 용어 풀이까지 동일한 검토 요청에 전달합니다. 추가 모델 호출 없이 기존 최대 4회 요청을 유지합니다.
- 각 오류는 어느 표시 항목의 오류인지 기록합니다. 인용이 그 항목에 실제로 존재해야 오류로 인정합니다. 요약에서 배경정보를 생략한 것 자체는 오류로 보지 않도록 검토 기준을 구분했습니다.
- 시각 전체 목록이 다르다는 이유로 종료 시각 오류를 생성하던 규칙을 제거했습니다. 단일 종료 시각이 명확한 경우만 규칙으로 비교하고, 날짜·시간대·여러 시각이 얽힌 경우 문맥 비교에 맡깁니다.
- F2 별도 작업 없이 중대한 오류만 최대 두 문장으로 표시합니다. 대조 중 / 대조 실패 / 일부 미확인 상태는 요약 아래 한 줄로 구분합니다. 진행 단계 완료 표시는 실제 결과 도착을 기준으로 합니다.
- 국가 미상, 해제·훈련·부정·조건 표현을 포함한 붙여넣기에는 보수적으로 기본 안전 안내를 제공합니다. wind chill을 강풍으로 매칭하지 않습니다. 이 필터는 완전한 다국어 의미 판별기가 아닙니다.
- 공식 출처 연결을 못 한 것을 “원문에 행동지시가 없다”라고 단정하던 문구를 수정했습니다.

## 프론트엔드 인계용 API 변경

Input.country: US | JP | unknown (기본 unknown). 국가 선택은 행동지침 선택에 쓰이며, 단위 없는 숫자를 화씨라고 단정하는 근거로 사용하지 않습니다.

POST /api/verify: 기존 text, translation, alert_id에 선택적 displayed 객체 추가. 허용 키는 summary, hazard_explanation, instruction_translation_ko, glossary이며 값은 각 표시 항목을 합친 문자열입니다. translation은 기존 전용 필드로만 받습니다. 추가 필드는 기존 클라이언트와 호환됩니다.

응답 Issue.field는 오류 발생 항목(기본 translation), Verification.checked_fields는 대조 대상으로 전달한 항목입니다. checked_fields는 각 항목의 정확성을 보증하지 않습니다.

## 검증

- 백엔드 61개 통과: 기존 날짜/단위 회귀 검사, 요약만 틀린 사례, 필드별 근거 오인, 표시 내용 전달, 시간대 변환 오탐, 국가 미상·해제·쓰나미 위험 없음, 입력 계약 검사.
- 프론트엔드 7개 통과: 국가 및 전체 표시 내용 전송, 검증 실패 상태, 기존 일본 조회/일괄 분석/AI 장애 시 지침 표시.
- TypeScript 및 배포 빌드 통과.
- 실제 Gemini 응답, 실제 재난문자 표본, 휴대전화 실기기 사용성은 이번 자동 검사에 포함하지 않았습니다. 배포 완료나 안전성 인증을 의미하지 않습니다.

## 다음 확인 단계

실제 미국·일본 문자에서 개인정보를 제거한 평가 표본을 만들고 날짜·발령/시작/종료·지역·단위·부정문·복합 재난별 정답을 검토해야 합니다. 실제 모델로 반복 평가한 뒤 요약 오류율과 의미 검증 누락을 기준으로 출시 여부를 결정합니다. 일반 행동지침 내용과 근거 연결은 재난별로 별도 검토해야 합니다. 현재 보수적 필터는 필요한 유형별 안내를 생략할 수 있어 이후 구조화된 위험 상태 판별로 개선할 여지가 있습니다.

API 키는 backend/.env 또는 서버 환경변수에 한 번 설정합니다. 공유 ZIP에는 실제 키를 넣지 않습니다.
