# ActionGuard Travel 2.7 — 연결된 사용 흐름

문자 입력 → 번역·검증·행동지침 → 같은 문자로 질문 → 공통 위치와 체류 일정 확인 → 주변 시설 → 길찾기.

- 공통 위치는 미국/일본과 장소 이름, 현재 위치 또는 지도 좌표로 등록합니다. 지도에서 선택한 위치를 분석 화면과 일정, 길찾기에서 재사용합니다.
- 지도에 갔다 돌아와도 분석 결과와 대화를 유지합니다. 위치나 문자가 달라지면 이전 맥락의 대화·진행 중 응답을 버립니다.
- 문자에 언급된 지원 재난 유형을 지도 필터로 연결합니다. 복합 재난은 유형을 직접 선택합니다. 연결은 대피 명령이나 개인 위치의 위험 판정이 아닙니다.
- 일본: 국토지리원(GSI)의 일반 피난소(sih), 재난별 지정 긴급대피장소(skhb01~08)를 조회합니다. 홍수·산사태·폭풍해일·지진·쓰나미·대규모 화재·내수 범람·화산을 구분합니다. 반경 0.5~10km입니다.
- 특정 재난 검색에는 해당 재난 지정이 있는 장소만 포함합니다. 일반 피난소의 재난 적합성은 미확인입니다. 폐쇄·사용 제한 표기 장소는 기본 제외하며 참고 목록에서도 길찾기를 차단합니다.
- 미국은 기존 FEMA/NYC 공식 자료를 사용합니다. 양국 모두 거리 순은 안전 순위가 아닙니다.
- 지도는 Leaflet/OpenStreetMap, 도보·자동차 경로는 FOSSGIS/OSRM을 사용합니다. Google Maps API 키와 결제 설정이 필요 없습니다. Gemini 번역·질문용 키는 기존 backend/.env 설정을 사용합니다.
- 주소 자동 검색은 제공하지 않습니다. 현재 위치, 지도 클릭 또는 좌표로 선택하세요. 도보 50km, 자동차 500km 이내를 지원합니다.
- 시설의 현재 개방·수용 가능 여부, 재난 통제·침수·실시간 교통 및 경로 안전은 확인되지 않습니다. 외부 서비스 실패 시 가짜 경로를 만들지 않습니다.

## 데이터·운영

공통 위치·대화·일정은 브라우저 메모리에서 유지하며 새로고침 시 초기화합니다. 사용자가 명시적으로 저장한 지도 목록만 기기에 남습니다. 저장한 목록은 최신 조회 전 길찾기에 사용하지 않습니다. 좌표는 시설/경로 조회 요청 시 서버와 해당 지도·경로 제공자에 전달됩니다.

GSI 데이터는 시정촌 제공 자료이며 갱신 지연·누락이 가능합니다. 404/빈 목록은 시설 부재의 증거가 아닙니다. 일부 구역 조회 실패도 표시합니다. 다운로드 자료에 출처·용도 구분·최신 상태 확인 안내를 함께 넣습니다.

공개 경로 서버 요청은 한 프로세스에서 초당 1회 이하로 제한하고 10분 캐시합니다. 여러 서버/워커를 운영할 때는 공통 제한기를 구현하거나 자체/계약 경로 서버를 사용해야 합니다. 공개 지도·경로 서비스에는 가용성 보장이 없으므로 정식 운영 전 이용 정책, 용량, 모니터링 및 대체 경로를 검토해야 합니다.

## 검증

2026-10-15: 백엔드 153개, 프론트엔드 36개 자동 테스트 및 배포 빌드 통과. 일본 실제 도쿄역 예시 좌표 반경 5km: 일반 피난소 263개, 지진 지정 장소 81개, 쓰나미 지정 장소 15개 조회(조회 시점 기준). 일본 도보 1,823.8m·자동차 1,684.3m 경로 응답 확인(서로 다른 도로 접근 지점). 차량 연결 불가 응답은 별도 안내합니다. 이 검증은 실제 개방이나 재난 중 경로 안전을 인증하지 않습니다. 이번 변경에서는 Gemini 모델 재평가를 실행하지 않았습니다.
