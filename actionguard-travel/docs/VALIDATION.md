## 최근 화면 변경

F1 입력, 번역, 이상 항목 확인, F3 행동지침을 단일 화면 흐름으로 모았습니다. 이번 사용성 개선에서는 F2의 내부 추출/검증 표시는 숨기고, 차이·미해결·확신 부족이 있을 때에만 사용자가 확인할 원문과 번역 근거를 보여줍니다. 번역은 핵심 설명과 최대 3개 요점을 먼저 보여주고, 전체 번역과 용어 설명은 접어서 제공합니다. NWS 조회는 좌표 기준을 기본으로 하며 현재 위치 입력은 사용자가 직접 눌러 요청합니다. 주 전체 조회에는 넓은 범위임을 알리고, 결과가 많을 때 제목/지역 필터를 제공합니다. 좌표 조회는 지정 좌표에 적용되는 NWS 경보 검색이며 임의 반경 경보 조회를 뜻하지 않습니다. F3 공식 지시는 한국어 번역을 먼저 보여주고 영문 원문은 펼쳐 볼 수 있게 했습니다.

이번 변경 후 프런트엔드 프로덕션 빌드와 Python 구문 컴파일은 통과했습니다. 기존 보고서의 테스트 수치는 해당 시점 결과이며, 현재 실행 환경에 `httpx`, `pydantic`, `pytest`가 없어 최신 백엔드 테스트 모음은 수집/실행하지 못했습니다.

추가 개선: 반복 시각이 포함된 경보에서 분 단위 한국어 시각을 읽지 못해 발생하던 오탐을 수정했습니다. 화면에는 중대하고 근거가 있는 오류만 최대 두 문장으로 표시합니다. 미국 경보의 화씨 온도는 화씨를 보존하면서 섭씨 환산값을 병기하고, 풍속은 mph와 km/h를 함께 표시합니다. 강풍에는 NWS의 실내 대피·차량 운행·전선 회피 수칙을 추가했으며, 공식 행동지시가 없으면 유형별 수칙 또는 FEMA 기본 경보 행동요령을 안내합니다. 프런트엔드 빌드와 시간/온도/풍속 및 강풍 안내 집중 확인은 통과했습니다. 전체 백엔드 테스트는 현재 실행 환경에 `httpx`와 `pydantic`이 설치되지 않아 수집 단계에서 실행하지 못했습니다. Python 구문 컴파일은 통과했습니다.

일본 지원: 미국/Japan 선택을 추가하고 JMA의 현행 `/bosai/warning/data/r8/{office}.json` 경보와 관할 지역 목록을 서버에서 조회합니다. 활성 경보는 시정촌 단위로 묶고 일본어 이름, 경보 등급, 발령 시각을 포함합니다. 공식 자료에 개별 행동지시가 없으면 일본어 경보 종류에 맞는 한국어 일반 안전안내를 보여주며, 이를 공식 명령과 구분합니다. 직접 붙여넣은 일본어 지진·쓰나미 문자는 F1~F3에서 분석할 수 있으나, 실시간 지진·쓰나미 피드는 연동하지 않았습니다. 이 변경 후 TypeScript 검사/Vite 프로덕션 빌드와 Python 구문 컴파일은 통과했습니다. 백엔드 테스트는 런타임 의존성이 없어 실행하지 못했습니다. JMA의 경보 안내는 [공식 페이지](https://www.jma.go.jp/jma/kishou/know/bosai/warning.html)에서 확인할 수 있습니다.

## 구현 범위

- F1: 미국 NWS 주·좌표별 및 일본 JMA 관할 지역별 공식 활성 기상 경보, 메타데이터/원문/출처, 중복 제거·캐시·오류/빈 상태, Gemini 번역/용어/요약, 영어·일본어 직접 입력, 선택 OCR.
- F2: 12종 핵심정보 독립 추출, 공식 정형 필드 우선, 규칙 + 의미 비교 + 실제 인용 검사, 네 판정, 근거 카드, 강조, 미해결 항목.
- F3: 서버 조회 원문과 일치할 때만 공식 instruction 표시. 미국 NWS 안전수칙 및 일본 기상 유형별 일반 행동요령을 공식 지시와 구분해 표시. 근거 없는 대피소·경로·시설 폐쇄 생성 없음.
- React Router 4화면, TanStack Query, Tailwind CSS, Radix/CVA 기반 shadcn 스타일 Button, Lucide, 반응형·테마·로딩/오류/빈 상태.
- FastAPI/Pydantic, 비동기 httpx, 타임아웃, 제한된 메모리 캐시, CORS, 비밀 미노출, 오류 종류/경로만 로그.

## 남은 검증과 제한

실제 Gemini 키를 설정한 뒤 해당 계정의 모델 접근·무료 한도·실제 한국어 출력 품질을 확인해야 합니다. 모델 응답을 모의한 검사는 실제 모델 품질을 입증하지 않습니다. OCR 엔진을 설치하고 실제 경보 이미지로 숫자·지명 인식 정확도를 확인해야 합니다. 운영 수준의 독립 정답셋 평가, 모든 시간대/단위/지명 변형의 비교, 부하·침투·전체 접근성 검사는 수행하지 않았습니다. 로컬 MVP를 공개 운영 서비스 수준으로 인증하지 않습니다.

## 보안

실제 키와 .env는 ZIP에 없습니다. 프론트엔드 소스/빌드에 API 키를 넣지 않습니다. 무료 프로젝트 확인 설정을 켜야 AI 요청이 실행되고, 모델/유료 티어 자동 전환은 없습니다. 앱은 Google 프로젝트의 실제 결제 상태를 통제하지 못하므로 Free tier 키 사용은 운영자가 확인해야 합니다. 공개 노출 대신 기본 127.0.0.1 로컬 바인딩을 사용합니다.
