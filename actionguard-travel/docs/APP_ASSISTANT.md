# 앱 전체 AI 도우미

경보 원문이 없어도 `/chat`에서 질문할 수 있습니다. AI 의도 분류와 기존 서버 기능을 연결합니다. 경보·시설·거리·알림 상태는 실제 조회와 서버 계산으로 결정합니다.

## 지원 기능

- 문자 번역·요약·의미 검증, 대응 단계 해석과 원문 후속 질문
- 미국 NWS·일본 JMA의 현재 지역 기상경보 조회
- 미국·일본 공식 시설 목록에서 반경 10km 내 직선거리 정렬, 지도·일반 경로 연결
- 일본 지진 관측·쓰나미 발표 조회와 전용 지도 연결
- 등록 체류 일정과 선택한 공식 경보의 위치·시간 비교
- 알림 서버 상태 확인과 설정 안내, 앱 사용법, 출처 기반 일반 안전수칙
- 최대 세 가지 요청 동시 처리, 최근 질문·조회 경보를 연결한 후속 질문

투자·오락·정치·일반 잡학은 범위 밖입니다. 임의 웹 검색·예약·구독 변경·실제 이동 수행은 지원하지 않습니다. 설정 변경은 해당 화면에서 사용자가 완료합니다.

## 개인정보와 실패 처리

질문·최근 대화·연결 원문은 Gemini로 전송될 수 있습니다. 질문에 직접 적은 개인정보도 포함될 수 있습니다. 등록 좌표·위치 이름·체류 시간은 모델 입력에서 제외합니다. 좌표는 공식 지역 판별·시설 조회·서버 계산에 사용합니다. 실시간 결과의 AI 설명에는 건수·종류·조회 제한 등 비식별 요약만 보냅니다. GPS는 버튼을 눌렀을 때만 요청합니다.

AI 연결 실패 시 실제 조회 카드와 규칙 안내를 유지합니다. 공식 조회 실패와 유효 경보 0건을 구별합니다. 위치·경보 변경 후 이전 응답은 폐기합니다. 복합 요청은 기능별 실패를 분리하고 각 기능을 최대 90초로 제한합니다.

## 한계

기상 조회는 모든 재난을 포함하지 않습니다. 일본 지진은 발생 후 관측 자료이며 긴급지진속보 수신 서비스가 아닙니다. 시설의 현장 개방·입소 가능·재난 적합성은 별도 확인이 필요합니다. 직선거리 최단과 안전한 대피 경로는 다릅니다. 일본 시정촌이 여러 경보 구역으로 나뉘면 지역 선택을 요청합니다. 공통 위치와 일정은 새로고침하면 지워집니다.
