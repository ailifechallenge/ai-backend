# 앱 전체 AI 도우미

경보 원문이 없어도 `/chat`에서 질문할 수 있습니다. AI 의도 분류와 기존 서버 기능을 연결합니다. 경보·시설·거리·알림 상태는 실제 조회와 서버 계산으로 결정합니다.

## 지원 기능

- 문자 번역·요약·의미 검증, 대응 단계 해석과 원문 후속 질문
- 미국 NWS·일본 JMA의 현재 지역 기상경보 조회
- 미국·일본 공식 시설 목록에서 반경 10km 내 직선거리 정렬, 지도·일반 경로 연결
- 일본 지진 관측·쓰나미 발표 조회와 전용 지도 연결
- 등록 체류 일정과 선택한 공식 경보의 위치·시간 비교
- 알림 서버 상태 확인과 설정 안내, 앱 사용법, 출처 기반 일반 안전수칙
- 최대 세 가지 요청 동시 처리, 최근 질문·조회 경보를 연결한 후속 질문

투자·오락·정치·일반 잡학은 범위 밖입니다. 임의 웹 검색·예약·구독 변경·실제 이동 수행은 지원하지 않습니다. 설정 변경은 해당 화면에서 사용자가 완료합니다.

## 개인정보와 실패 처리

질문·최근 대화·연결 원문은 Gemini로 전송될 수 있습니다. 질문에 직접 적은 개인정보도 포함될 수 있습니다. 등록 좌표·위치 이름·체류 시간은 모델 입력에서 제외합니다. 좌표는 공식 지역 판별·시설 조회·서버 계산에 사용합니다. 실시간 결과의 AI 설명에는 건수·종류·조회 제한 등 비식별 요약만 보냅니다. GPS는 버튼을 눌렀을 때만 요청합니다.

AI 연결 실패 시 실제 조회 카드와 규칙 안내를 유지합니다. 공식 조회 실패와 유효 경보 0건을 구별합니다. 위치·경보 변경 후 이전 응답은 폐기합니다. 복합 요청은 기능별 실패를 분리하고 각 기능을 최대 90초로 제한합니다.

## 한계

기상 조회는 모든 재난을 포함하지 않습니다. 일본 지진은 발생 후 관측 자료이며 긴급지진속보 수신 서비스가 아닙니다. 시설의 현장 개방·입소 가능·재난 적합성은 별도 확인이 필요합니다. 직선거리 최단과 안전한 대피 경로는 다릅니다. 일본 시정촌이 여러 경보 구역으로 나뉘면 지역 선택을 요청합니다. 공통 위치와 일정은 새로고침하면 지워집니다.

## 검증 (2026-10-16)

백엔드 373개·프론트엔드 108개 테스트 통과, 백엔드 선택적 점검 2개 건너뜀. 빌드 성공. 원문 없는 질문·개인정보 제외·조회 실패·만료·시정촌 분할·시설 필터·후속 원문·외부 링크 차단·이전 응답 폐기를 점검했습니다. 공개 시험 좌표로 미국·일본 경보와 도쿄 시설 조회 및 Gemini 근거 설명을 확인했습니다. 실제 호출 추가 기록: `evaluation/runs/app-assistant-live-2026-10-16.json`. 출시 승인 또는 실제 재난 현장 검증을 뜻하지 않습니다.


## 장소·지진 답변 개선 (2026-10-16)

- “도쿄역에서 가까운 지진 대피소”, “시카고 주변 대피소”처럼 질문에 명시된 장소를 검색 기준으로 사용합니다. 도시 대표 지점과 실제 위치를 구별하고, 복수 후보는 선택한 뒤 조회합니다. 등록 위치를 임의로 덮어쓰지 않으며 후속 질문에서 대화의 조회 위치를 이어서 사용합니다.
- 지진은 최신 발표 순서가 아닌 발생 시각으로 정렬하여 진앙 지역·발생 시각(일본 시간)·규모·최대 관측 진도·깊이를 직접 답합니다. 선택한 사건을 바로 지도에서 열 수 있습니다. 취소·미래 발생·오래된 조회 응답은 현재 관측으로 표시하지 않습니다. 최신 관측을 사용자가 방금 느낀 사건으로 단정하지 않습니다.
- 대피시설 답변은 전체 건수를 읊는 대신 첫 시설과 실제 직선거리를 먼저 보여줍니다. 재난명을 말하면 해당 재난의 적합성 필터를 유지합니다.

도시 검색: Open-Meteo/GeoNames. 도쿄역은 출처를 검토한 Wikidata Q283196 좌표를 사용합니다. 일반 지명·랜드마크는 GSI 검색과 Photon을 보조 사용하며, 검색 실패 시 좌표를 만들어 내지 않습니다. GSI 반환 제목이 요청 장소와 일치하지 않으면 사용하지 않습니다.

장소 검색은 사용자 요청 시에만 실행하고 서버에서 캐시·호출 간격 제한을 적용합니다. Open-Meteo 무료 서비스는 비상업용 정책, Photon 공개 서버는 호출 제한·가용성 제한이 있으므로 상용 배포 전 자체 운영 또는 계약한 제공자로 전환해야 합니다. `ACTIONGUARD_CITY_SEARCH_URL`, `ACTIONGUARD_PHOTON_URL`로 서버 주소를 교체할 수 있습니다. 관련 문서: https://open-meteo.com/en/docs/geocoding-api, https://github.com/komoot/photon. Google Maps API는 사용하지 않습니다.

최종 회귀 검증: 백엔드 385개·프론트엔드 110개 통과(백엔드 선택적 2개 건너뜀). 도구 답변에 담긴 등록 위치·체류 시각이 후속 AI 입력으로 재전송되지 않도록 모델에는 사용자 작성 대화만 전달합니다. 실제 세 질문 결과는 evaluation/runs/chat-place-regression-2026-10-16.json에 기록했습니다.

로컬 실행 버전 파일 목록을 data/runtime-files.json 한 곳으로 통합하여 프론트·서버의 버전 확인값 불일치를 수정했습니다. 시작.command의 정상 기동과 API 연결 일치를 확인했습니다.
